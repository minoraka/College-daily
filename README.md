# Учебная доска

Сайт на React (Vite), где студенты группы отмечают прогресс заданий на канбан-доске и пишут «дейлики».

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка: `npm run build` (результат в `dist/`). Проверка кода: `npm run lint`.

## Как пользоваться

- **Вход.** Выберите готовый профиль (преподаватель или демо-студент) или создайте нового студента по имени.
- **Доска.** 4 колонки: *К выполнению → В работе → На проверке → Готово*. Карточки можно перетаскивать
  мышью или двигать кнопками ‹ ›. Фильтр «Мои» показывает только ваши карточки.
- **Правила.** Студент создаёт карточки для себя и двигает свои; в «Готово» карточку переводит только
  преподаватель после проверки. Преподаватель создаёт карточки любому студенту и правит всё.
- **Дейлик.** Кнопка «Написать дейлик»: что сделал, что планирую, что мешает, связанная карточка.
  «Сохранить черновик» виден только вам, «Отправить на доску» публикует в общую ленту на вкладке «Дейлики».
  Сверху ленты видно, кто сегодня ещё не отправил дейлик.

## Важно: где хранятся данные

Сейчас всё лежит в `localStorage` браузера: данные не уходят на сервер, работает между вкладками
одного браузера. Чтобы доска была общей для всех компьютеров, нужен сервер — замените функции в
`src/store.js` (`actions`) на запросы к API, интерфейс менять не придётся.
